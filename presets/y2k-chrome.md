# Style contract: Y2K Chrome

> Every image looks like a 1999 CD-ROM menu screen: liquid chrome, iridescent bubbles, a lens flare nobody asked for. Futuristic, from the past.

## Contract (every image, every mode)

| Part | Rule |
| --- | --- |
| **Finish** | Late-90s 3D render: glossy liquid chrome, hard specular highlights, one lens flare, a faint CRT scanline and slight JPEG softness over the whole frame. |
| **Palette** | Anchor: electric cyan `#00E5FF`. Supporting: chrome silver `#C9D3DD`, deep space blue `#0A0F3C`. Accent: acid lime `#B6FF00`, once, small. Never: warm earth tones, beige, matte paper, film grain. |
| **Composition** | One chrome hero object floating centred on a deep gradient or a glowing wireframe grid horizon. Symmetric, a little too shiny. |
| **Subject** | One object, rendered as if it were liquid chrome or translucent iMac plastic. No people, no real brand logos, no text. |
| **Mood** | Optimistic, techno, dial-up utopia. Never: gritty, vintage-paper, realistic, minimal-flat. |

## Modes (pick exactly one per image)

| Mode | Clause to copy into the prompt |
| --- | --- |
| **Chrome render** | a 1999 3D render, liquid chrome object, like a Windows 98 screensaver or a CD-ROM menu |
| **Frutiger Aero** | a mid-2000s Frutiger Aero illustration: glossy aqua glass, bubbles, sky blue gradients, green grass |
| **Translucent plastic** | a product shot in translucent Bondi-blue iMac G3 plastic, internal parts visible |

## Off-brand tells

| Drift | Fix |
| --- | --- |
| Modern clean CGI | Add "rendered in 1999 software, slightly low-poly, JPEG softness, CRT scanlines." |
| Matte surfaces | Say "liquid chrome with hard white specular highlights." |
| Cyberpunk neon city | Restate one object, no city. |

## Example prompt

> A lighthouse made entirely of liquid chrome, floating above a glowing cyan wireframe grid horizon, its lamp sending out a single acid lime #B6FF00 beam. Rendered as a 1999 3D render, like a Windows 98 screensaver or a CD-ROM menu. Electric cyan #00E5FF reflections, chrome silver #C9D3DD body, deep space blue #0A0F3C gradient sky. Hard specular highlights, one lens flare, faint CRT scanlines and slight JPEG softness over the whole frame. Optimistic, techno, symmetric and centred. Full bleed, no border. The cyan is #00E5FF. No text, no letters, no logos, no watermarks.
